🎬 LIVE VIDEO STREAMER

Live Video Player

Stream online video from a direct HTTP/HTTPS link with a modern dark UI. Parallel downloads and an in-memory buffer keep playback fast, smooth and interruption-free.

⬇️ Download for Windows View on GitHub Releases

Features

⚡ Parallel downloads

Fetches media over multiple simultaneous connections for higher throughput.

🧠 RAM cache

Configurable in-memory buffer (default 256 MiB) smooths playback on slow links.

🎞️ HTML5 playback

Streams directly inside the app with native seeking and full controls.

📼 VLC fallback

Plays formats the browser can't — MKV, AVI and more — via the bundled VLC engine.

📡 Range support

Works with Range-capable servers and falls back gracefully for servers without it.

🔒 Loopback proxy

Streams through a local proxy so your original media link stays hidden.

Quick start

pip install -r requirements.txt
python main.py

Play a link on startup: python main.py --url "https://example.com/video.mp4" --cache 512
